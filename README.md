# my_introduction

GitHub Pages で公開するための自己紹介サイトです。

## 編集する場所

- `index.html`: 名前、自己紹介、リンク、活動内容を編集します。
- `styles.css`: 色、余白、文字サイズなどの見た目を編集します。

## GitHub Pages で公開する手順

1. このフォルダを GitHub のリポジトリに push します。
2. GitHub のリポジトリ画面で `Settings` → `Pages` を開きます。
3. `Build and deployment` の `Source` を `Deploy from a branch` にします。
4. `Branch` を `main`、フォルダを `/root` にして保存します。
5. 数分後に表示される URL へアクセスします。

## 差し替え候補

- `Yuu Shimizu`
- `your.email@example.com`
- GitHub / X / note / Qiita / LinkedIn の URL
- `About`、`Interests`、`Works` の文章
